# Fonts — TT Interphases (web subset)

This directory ships **WOFF2 web fonts only**, for the weights referenced by
`../colors_and_type.css`. They exist so HTML artifacts (slides, previews,
prototypes) render with the real brand typeface in a browser.

## Bundled weights

| Family | Weight | Style | File |
|---|---|---|---|
| TT Interphases | 300 Light | normal | `TT Interphases Light.woff2` |
| TT Interphases | 400 Regular | normal | `TT Interphases Regular.woff2` |
| TT Interphases | 500 Medium | normal | `TT Interphases Medium.woff2` |
| TT Interphases | 600 DemiBold | normal | `TT Interphases DemiBold.woff2` |
| TT Interphases | 700 Bold | normal | `TT Interphases Bold.woff2` |
| TT Interphases | 900 Black | normal | `TT Interphases Black.woff2` |
| TT Interphases | 900 Black | italic | `TT Interphases Black Italic.woff2` |
| TT Interphases Mono | 400 Regular | normal | `TT Interphases Mono Regular.woff2` |
| TT Interphases Mono | 700 Bold | normal | `TT Interphases Mono Bold.woff2` |

## The full family

TT Interphases is a **commercial TypeType typeface**. The complete desktop
family (OTF/TTF, all weights and italics) is **not redistributed in this
repository**. Obtain it from the SBP brandbook or the SBP marketing team:

- Brandbook: <https://brandbook.schubergphilis.com>
